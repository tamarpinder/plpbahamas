# Claude Code Assistant - Standard Workflow

## 7 Essential Rules for Project Development

### 1. **Think Through & Plan First**
- Analyze the problem thoroughly
- Read the codebase for relevant files
- Write a comprehensive plan to `tasks/todo.md`

### 2. **Create Actionable Todo Lists**
- The plan should contain a clear list of todo items
- Each item should be specific and checkable
- Items should be marked as complete when finished

### 3. **Get Plan Approval**
- Before beginning any work, check in with the user
- User will verify and approve the plan
- Wait for confirmation before proceeding

### 4. **Execute & Track Progress**
- Work through todo items systematically
- Mark items as complete as you progress
- Maintain clear status tracking

### 5. **Provide High-Level Updates**
- Give concise explanations of changes made
- Focus on what was accomplished, not implementation details
- Keep updates brief and focused

### 6. **Prioritize Simplicity**
- Make every task and code change as simple as possible
- Avoid massive or complex changes
- Each change should impact as little code as possible
- Everything is about simplicity and minimal impact

### 7. **Document & Review**
- Add a review section to the `todo.md` file
- Summarize all changes made
- Include any other relevant information
- Provide clear documentation of work completed

---

## Workflow Summary

1. **Plan** → 2. **List Tasks** → 3. **Get Approval** → 4. **Execute** → 5. **Update** → 6. **Keep Simple** → 7. **Review**

This workflow ensures clear communication, systematic progress, and maintainable code changes.
